# 我的AI语言：

## 功能视角：

1. 定位：NLP与AI整体，主体职责，分别与Shell语言和各高级语言进行比对(AI语言模糊/高级语言量化)。

2. 产品：

2.1. 主导：deepseek(纯国产化/专注文本解决问题)，豆包(ChatGPT+抖音/综合能力强/方便) ，全免费(手机/电脑/网页)
2.2. 配合：语言沟通/语音转文字/翻译/文字识别，仿人(视觉/听觉/语言交互/存储/执行)
2.3. 发展：基础平台化(渠道越来越广越多样)，AI语言编程化(自身编程/多语言配合)，巩固AI语言的AI核心化地位

3. 学习：语文/数学/英语/计算机，基础教育的重要性，广义的信息技术/一部分信息科学/一部分物理

## 使用视角：

1. 普通用户：语言直接问，只参考，需实践确认；生活/生产/科技，图文并茂；越精细越好，迭代问，专业成体系

2. 编程人员：设计(代码阅读/产品分析/结构分析)/开发(写Demo/代码提示/自动修复)/调试(代码检查/配合解决问题)

3. 未来场景：设备听语言/理逻辑/再执行；输入文字当作程序；学习记忆复制人说的话和文字，参数/回调/同步异步

## 开发视角：

1. 实现：功能层面，NLP/搜索(百度/谷歌)/数据分析/子工具(系统/行业)；非功能层面，处理/存储/传输的显著提升

2. 理论：语言范畴；开发，硬件(汇编)/系统(C/Shell)/应用(高级语言/Shell)/人(NLP)；使用，机器(Shell)/人(NLP)

3. 科学：仿生(脑与迷走神经/章鱼/黏菌)/量子，物理(量子计算通讯/物质时空)，数学(语言科学/建模表达/逻辑公理)

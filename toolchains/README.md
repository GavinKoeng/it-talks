# 工具链的角度去看it
是程序员使用计算机的工具，因此从二者的交互入手，来完整讲解各类编程语言和交互机理

## 编程语言（我的XXX，my-xxx）

是工具链的主要对外接口，是程序员用来与计算机进行交互的语言；将从第一人称““我”的视角来进行阐述

## 编译解释（程序的XXX，program-xxx）

是工具链的核心实现，用来生成程序；将从程序的视角来进行阐述

## 调试监控（运行时XXX，runtime-xxx）

是工具链的主要扩展工具，用来配合程序员分析程序的运行；将从运行时环境的视角来进行阐述

## 其他工具（工具，tools）

其他同工具链相关的各类工具；将从各个工具本身的视角来进行阐述。

# 程序的编译链接：

## 功能视角：

1. 定位：本职工作(涉及的高级语言/与AI语言的关系)；api是各语言(含汇编)参考手册

2. 产品：gcc/clang/llvm/binutils，c/c++/go/rust，debuild/rpmbuild, iso/osrepo.

3. 学习：从使用入手，从学习语言入手，做扎实编程基础，借助AI

## 使用视角：

1. 独立构建：编译脚本(直接/make/qmake/cmake/ninja/gn/IDE)/编译器/链接器/打包

2. 集成构建：deb/rpm编包；安卓鸿蒙(估计windows/苹果也都类似)；内部定制

3. 系统制作：输入内容和输出结果都要描述清楚；交叉编译/本地编译/标准编包

## 开发视角：

1. 编译原理：前端(lex/yacc/功能)/中间语言/后端/opcode，优化，循环点/自举/交叉编译

2. 链接原理：文件布局/静态/动态链接；指定入口/导出符号/段设置(异构链接)；基本库

3. 实现方法：增加语言(前端)/增加平台(后端)，解决bug/代码优化；单元测试/中间文件

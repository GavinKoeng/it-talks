# 计算机视角看it
## 介绍
从底层硬件到上层应用，从二进制逻辑到人机交互，全方位讲解计算机的软硬件运行原理。

## 内容架构
计算机基础
 硬件层 (Hardware Layer)
    CPU架构与指令集
    内存层次结构
    存储系统原理
    输入输出设备
 系统层 (System Layer)
    操作系统原理
    进程与线程管理
    内存管理机制
    文件系统设计
 网络层 (Network Layer)
    网络协议栈
    数据传输原理
    网络安全基础
 应用层 (Application Layer)
     软件架构模式
     用户界面设计
     人机交互原理

# 程序的加载运行：

## 功能视角：

1. 定位：程序必经阶段，环境搭建和做集成/联调，概要设计的关键支撑，安装部署(静态)/加载运行(动态)
2. 内容：普通(OS启动流程/用户态运行加载/内核态运行加载)/容器(chroot/docker)/异构(X11/昇腾)/虚机(QEMU/)
3. 学习：实践Linux(概要设计/集成调试/主动思考)/理论科普(体系思维/开拓视野/兴趣爱好)/辅助AI(DeepSeek/豆包)

## 使用视角：

1. 整体概述：内核引导/内核运行/根文件系统/内核模块加载/用户态运行(加载与解释)，定制环境/异构计算/整体集成
2. 定制环境：硬链接/库环境变量/chroot/flatpak/docker/KVM(QEMU)/模拟运行(qemu_static)/解释模拟
3. 异构计算：X11，加载运行(多elf文件+多om文件/runtime/cpu/驱动/AIcore)/内存状态(层次/数据传递/CPU/AIcore)

## 开发视角：

1. 普通加载：触发/内核(do_fork/exec)/加载器(ld-linux/qemu_static)/加载程序/加载关联库/动态加载，内核模块
2. 整体运行：进程线程/地址布局/首次触发跨动态库调用/后继动态库调用/可执行数据段/定制加载布局(qemu/wine)
3. 基础平台：OS引导运行/容器(namespace/cgroup/overlayfs)/异构(运行时/内核态驱动/AI卡)/虚机(指令/OS/设备)

# 程序的编译链接：

## 功能视角：

1. 定位：本职工作(前端各高级语言和AI语言/后端各CPU和AI卡)；使用的api是各语言(含汇编/AI卡)参考手册

2. 产品：

2.1. 分类：线性编译和图编译原理，流程控制+数据(标量/矢量/张量)处理+IO处理；llvm(msvc/gcc/atc)；发布

2.2. 实例：c(ai)/c++(ai)/go/rust/mesa/cuda/昇腾/python(ai)/js/java，lld等/binutils，deb/rpm, iso/osrepo

2.3. 发展：图编译与线性编译紧密绑定/普遍支持；LLVM通用，msvc/gcc/atc专用，每个领域两个(通用/专用)；AI语言

3. 学习：从使用入手，从学习语言入手，做扎实编程基础，详细了解环境(尤其Linux)，，对原理感兴趣，借助AI

## 使用视角：

1. 独立构建：编译脚本(直接/make/qmake/cmake/ninja/gn/IDE)/编译器/链接器/二进制工具/打包

2. 集成构建：deb/rpm编包/做盘与下载源；安卓鸿蒙(估计windows/苹果也都类似)/适配厂商/交叉编译；内部定制

3. 系统制作：输入(源码+裸机+各阶段输入内容)/输出(各阶段输出内容)；交叉编译/本地编译/标准编包

## 开发视角：

1. 编译原理：前端(功能/线性/图)/中间语言(优化)/后端(LTO/汇编/opcode)，起始/自举/交叉，开发框架

2. 链接原理：文件布局(elf/om)/静态/动态链接/LTO，指定入口/导出符号/段设置(异构链接)，支撑库

3. 内容方法：增加语言或功能(前端)/增加平台(后端)，解决bug，代码优化；单元测试/中间文件

## 综合示例：

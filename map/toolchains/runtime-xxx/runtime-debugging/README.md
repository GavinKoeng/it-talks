# 运行时调试：

## 功能视角：

1. 定位：动态和静态，运行时，同时跨静态代码与运行时(动态与静态); 解决运行时问题的关键/直接/根本/的方法，包括(系统/逻辑/机理)，重型处理(不全适合)
2. 产品：
2.1. 语言：(汇编/c/c++/rust/go)/(gdb/lldb/windbg/IDE), go/(delv/IDE)，java/(JDWP/jdb/IDE), js/(inspect/ndb/IDE/浏览器), python/(各pdb/IDE), shell/x，汇编/x64dbg
2.2. 平台：Win(VS+WinDbg), Linux(GDB/LLDB+KGDB/KDB+Crash), 安卓(lldb/AS)，苹果PC和手机(lldb/内核不公开)，嵌入式/(gdb/lldb/IDE和硬件调试都平台相关)
2.3. 环境：切换(混合模式调试)，场景(命令行/集成开发环境(VS/VSC/Xcode/AS/IDEA/Eclipse)/浏览器/多机调试)，动静(x64dbg+IDA/gdb+objdump/其他语言例如dex)
3. 学习：实践(具体项目+兴趣)/理论科普(调试本身+开发语言+平台环境)/AI辅助(产品选择+使用方法+了解原理)

## 使用视角：

1. 概述：参见程序员的调试测试，并给出4个综合示例，进行整体描述

## 实现视角：

1. 原理：进程控制(用户态ptrace进程跟踪/内核态和虚拟机都自带监控)/断点(硬件调试寄存器和软件异常)/信息获取写入
2. 功能：
2.1. 流程控制：定目标(新增/切换/移除)，设触发(代码类/数据类/混合)，控执行/(精细/进/出/单(源/反)/(启停/线/进程的暂/恢)/(跟进/子进程)
2.2. 信息获取：进程(模块加载+全局变量和函数/内存布局/进线列表)/线程(寄存器/局部存储/堆栈+调用链)/段数据(源代码/反汇编代码/堆)
2.3. 内容修改：寄存器，私有内存(TLS/栈/堆/代码/数据)，共享内存
3. 交互：界面(命令行/IDE/混合)，运行环境(标准与内核/虚拟机与浏览器/多机进程)，特殊场景(崩溃转储/反调试与加壳/虚拟机自身与实时与嵌入式)

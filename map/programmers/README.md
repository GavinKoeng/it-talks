# 程序员
从程序员角色入手，来阐述同IT相关的各方面内容

## 程序员看XXX (programmer-view-xxx)

从程序员的视角来看待同IT相关的各方面内容，包括计算机，自己的工作，其他相关人员的配合，以及教育，学历，年龄，就业，创业，企业，行业，产业，经济和社会等

## 程序员的XXX (programmer-xxx)

介绍程序员本身(对象)，包括：程序员的核心属性(对象属性)，专有的生活环境(运行环境)，以及专有的活动内容(对象方法)

## 程序员与XXX (programmer-and-xxx)

从各种不同角色的视角来看待程序员，包括：IT相关的其他人员，教育，企业，行业，产业，经济和社会等
